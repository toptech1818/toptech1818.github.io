Scope

This policy covers the internal tools listed on this site (including the application registered with Google as "TTJ CRM"). They are used only by the owner of Toptech, Thailand, and are not available to the public.

Google user data

  • The application requests only the drive.file permission. It can access only files and folders that the application itself creates.
  • It uses this access solely to store business files in the owner's own Google Drive.
  • It does not read other files, does not share Google user data with any third party, does not sell data, and does not use data for advertising.
  • Google user data is not used to train artificial intelligence or machine learning models.

Data retention and deletion

Files remain in the owner's Google Drive until the owner deletes them. Access can be revoked at any time at myaccount.google.com/connections.

Personal data (Thailand PDPA)

Personal data is processed in accordance with Thailand's Personal Data Protection Act B.E. 2562 (2019). Requests about personal data can be sent to the contact below.
